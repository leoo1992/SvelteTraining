# Svelte Training

Repositório de estudo com um projeto Svelte 3 baseado no template Rollup. O código de exemplo está dentro de `ola-svelte` e inclui dependências de Three.js.

## Stack
- Svelte 3
- Rollup
- TypeScript
- Three.js

## Como executar

```bash
cd ola-svelte
npm install
npm run dev
```

O comando `npm run dev` inicia o Rollup em modo watch. Em outro terminal, use `npm run start` para servir a pasta `public`.
