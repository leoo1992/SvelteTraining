# Svelte Training

A study repository containing a Svelte 3 project based on the Rollup template. The example code is under `ola-svelte` and includes Three.js dependencies.

## Stack
- Svelte 3
- Rollup
- TypeScript
- Three.js

## Run

```bash
cd ola-svelte
npm install
npm run dev
```

The `npm run dev` command starts Rollup in watch mode. In a separate terminal, use `npm run start` to serve the `public` folder.
